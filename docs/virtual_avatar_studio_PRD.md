# 🎭 3D 버츄얼 아바타 스튜디오 — 완전 기획서 (PRD)

> 라이브 방송 플랫폼 내장형 | 개발자 전달용 상세 기획서 v1.0  
> MoCoMo `/avatar/studio` · 현재 2D 프로토타입 → 3D 전환 로드맵

---

## 1. 프로젝트 개요

### 서비스 정의

라이브 방송 플랫폼 내부에서 유저가 **브라우저만으로** 자신만의 3D 버츄얼 캐릭터를 직접 제작하고, 방송에 실시간으로 연결하여 사용할 수 있는 **인앱 아바타 크리에이터**이다.

### 현재 상태 (v0 — 2D 프로토타입)

| 항목 | 상태 |
|------|------|
| 라우트 | `/avatar/studio` (사이드바: 라이브 스튜디오) |
| 렌더링 | Canvas 2D (평면 벡터 아바타) |
| UI | MoCoMo folk 디자인 (`live-page-shell`, `live-studio-panel`) |
| 저장 | localStorage 프리셋 |
| 방송 연동 | 미구현 (PNG 내보내기만) |

### 목표 상태 (v1 — 3D)

| 항목 | 목표 |
|------|------|
| 렌더링 | Three.js + WebGL2 실시간 3D |
| 아바타 | VRM 기반 + 스타일별 셰이더 |
| 트래킹 | MediaPipe Face Mesh → 표정·시선 |
| 방송 | WHIP/OBS 브라우저 소스/VTube Studio API |

### 지원 아바타 스타일 (4종)

| 스타일 | 설명 | 레퍼런스 |
|--------|------|----------|
| **애니메이션 / 버츄버** | 셀 쉐이딩, 큰 눈, 일본 애니풍 | VRoid Studio, VTuber |
| **리얼리스틱** | PBR 재질, 실사에 가까운 인체 비율 | MetaHuman, Ready Player Me |
| **카툰 / 귀여운** | 과장된 비율, 머리 크고 몸 짧음 | 제페토, Bitmoji |
| **SF / 사이버펑크** | 홀로그램 소재, 사이보그 파츠, 네온 | Cyberpunk 2077, NieR |

├──────────────┬──────────────────────────┬───────────────────────┤
│              │                          │                       │
│  좌측 패널   │      3D 뷰포트 (중앙)    │    우측 패널          │

└─────────────────────────────────────────────────────────────────┘

### MoCoMo UI 통합 원칙

- **앱 셸 유지**: 기존 `live-page-shell`, `folk-card`, `live-hero` 톤 (크림·코발트·테라코타)
- **뷰포트만 다크/씬 배경**: 3D 프리뷰 영역만 어두운 씬 또는 HDRI — 패널은 앱 라이트 테마
- **사이드바 진입**: `라이브` ↔ `라이브 스튜디오` ↔ `중고거래` 순서 유지

## 3. 헤더 (상단 바)

### 위치

화면 최상단, 전체 너비, 높이 56px. MoCoMo `live-hero` 스타일 (다크 전용 `#0d0d1a` 아님 — folk 톤 우선)

### 구성 요소 (좌→우 순서)

**[좌측]**

- 🔵 서비스 로고 + "아바타 스튜디오" 텍스트
- 현재 아바타 이름 (클릭 시 인라인 편집 가능, 기본값: "내 아바타")

**[중앙]**

- 스타일 선택 탭 4개: `애니메이션` | `리얼리스틱` | `카툰` | `사이버펑크`
  - 탭을 클릭하면 → 3D 뷰포트의 셰이더·재질 전체가 해당 스타일로 즉시 전환됨
  - 전환 시 0.4초 페이드 트랜지션 적용

**[우측]**

- `← 실행취소` 버튼 (Ctrl+Z 단축키 동일)
- `→ 재실행` 버튼 (Ctrl+Shift+Z)
- `💾 저장` 버튼 → 클릭 시 현재 상태를 JSON으로 로컬스토리지 + 서버 자동 저장, 완료 시 "저장됨 ✓" 토스트 메시지 1.5초 표시
- `📤 내보내기` 버튼 → 클릭 시 내보내기 모달 팝업 (섹션 9 참고)
- `🎥 방송 시작` 버튼 (강조 색상, `folk-terracotta`) → 클릭 시 현재 아바타를 방송 오버레이에 연결하는 설정 모달 실행

## 4. 좌측 패널 — 신체 & 얼굴 편집

### 위치

화면 좌측, 너비 320px, 전체 높이, 내부 스크롤 가능. `live-studio-panel` 컴포넌트 재사용

### 상단 탭 네비게이션 (패널 내부 상단 고정)

```
[ 신체 ] [ 얼굴 ] [ 피부 ] [ 메이크업 ]
```

탭을 클릭하면 해당 섹션으로 스크롤 이동 + 탭 언더라인 강조

---

### 4-1. 신체 탭

#### [섹션] 기본 체형

- **성별 표현 선택** (라디오 버튼 3개, 가로 나열)
  - `여성형` | `남성형` | `중성형`
  - 선택 시 → 어깨 너비, 골반 비율, 가슴 비율 기본값 자동 조정됨
  - 캐릭터가 해당 프리셋 체형으로 0.3초 내 자연스럽게 모핑됨

- **키 슬라이더** 범위: 140cm ~ 210cm, 기본값 165cm
  - 슬라이더 오른쪽에 현재 수치 실시간 표시 (예: `168cm`)
  - 드래그 시 3D 뷰포트 캐릭터가 실시간으로 키 변화 반영

- **체형 슬라이더 6개** (각각 0~100 범위):
  - `어깨 너비` → 값 높일수록 어깨가 넓어짐
  - `가슴 사이즈` → 값 조절로 흉부 볼륨 변경
  - `허리 굵기` → 값 낮출수록 잘록해짐
  - `복부 볼륨` → 0이면 복근형, 100이면 통통형
  - `엉덩이` → 크기 및 돌출도
  - `허벅지/다리 굵기` → 전체 하체 볼륨

- **근육 슬라이더** 0~100
  - 0: 마른 체형, 50: 보통, 100: 근육질
  - 근육 슬라이더와 체형 슬라이더는 서로 영향을 줌 (근육 높으면 어깨 자동으로 약간 넓어짐)

#### [섹션] 팔 & 다리

- `팔 길이` 슬라이더
- `팔뚝 굵기` 슬라이더
- `손 크기` 슬라이더
- `다리 길이` 슬라이더 (키 슬라이더와 연동됨, 비율 유지 체크박스 제공)
- `발 크기` 슬라이더

## 5. 중앙 — 3D 뷰포트

### 위치

좌우 패널 사이, 나머지 전체 너비, 배경 씬 포함. `live-studio-panel` 프레임 + 내부 WebGL 캔버스

### 기본 조작

- **마우스 왼쪽 드래그** → 카메라 오빗 (캐릭터 주변 회전)
- **마우스 휠** → 줌 인/아웃
- **마우스 오른쪽 드래그** → 카메라 패닝
- **더블클릭 (신체 부위)** → 해당 부위에 해당하는 편집 슬라이더로 좌측 패널 자동 포커스

### 뷰포트 상단 툴바 (캔버스 내부 우상단 플로팅)

- `앞면` | `뒷면` | `좌측` | `우측` | `전체` 카메라 프리셋 버튼 (클릭 시 해당 뷰로 스냅)
- `그리드` 토글 (바닥 그리드 표시/숨김)
- `조명 설정` 버튼 → 클릭 시 조명 패널 사이드 팝오버 표시
  - 조명 프리셋: `스튜디오` | `야외` | `네온 나이트` | `드라마틱`
  - 개별 조명 강도 슬라이더 3개 (Key / Fill / Rim)
  - 환경맵 선택: `스튜디오 흰` | `우주` | `도시 야경` | `자연 숲`
- `배경 설정` 버튼 → 클릭 시 배경 선택 패널 팝오버
  - 배경 종류: `투명 (크로마키)` | `단색` | `그라디언트` | `이미지 업로드` | `영상 업로드`

### 뷰포트 하단 툴바 (캔버스 내부 하단 고정)

- `⟳ 자동 회전` 토글 버튼 → ON 시 캐릭터가 Y축으로 천천히 회전
- `🔍−` 축소 / `🔍+` 확대 버튼
- `⊡ 초기화` 버튼 → 카메라 뷰 원위치
- **애니메이션 재생 바** (중앙):
  - `◀◀` 처음으로 | `▶ / ⏸` 재생/정지 | `▶▶` 다음 애니메이션
  - 현재 재생 중인 애니메이션 이름 표시 (예: "기본 대기 동작")
- `📸 스냅샷` 버튼 → 현재 뷰 PNG로 즉시 다운로드
- `🎞 짧은 영상 녹화` 버튼 → 클릭 시 3초 GIF 혹은 10초 MP4 녹화 후 다운로드

### 뷰포트 좌하단 — 실시간 정보 오버레이 (작은 글씨)

- 현재 폴리곤 수 (예: `△ 48,320`)
- 현재 FPS (예: `FPS: 60`)
- 현재 아바타 스타일 (예: `애니메이션`)

#### [섹션] 헤어 컬러

  - 검정, 짙은 갈색, 갈색, 골든 블론드, 은발, 흰색, 빨강, 파랑, 초록, 보라, 핑크, 청록
- **그라디언트 (투톤)** 토글:

  - `그라디언트 시작 위치` 슬라이더 (뿌리 ~ 끝 50% 지점 등)
- **하이라이트** 토글:
  - 하이라이트 색상 + 강도 슬라이더

#### [섹션] 헤어 세부 조정

- `볼륨` 슬라이더 (0: 납작, 100: 풍성)

- `끝부분 스타일`: `자연스러운` | `바람에 날림` | `젖은 느낌` | `스파이크`
- `광택` 슬라이더

#### [섹션] 특수 헤어 효과

- `반짝이 헤어` 토글 + 색상
- `파티클 헤어` 토글 (별, 하트, 꽃잎 등이 헤어 주변에 떠다님)
- `불꽃 헤어` 토글 + 색상

### 6-4. 애니메이션 탭

#### [섹션] 기본 동작 (Idle / Loop)

- 목록 (라디오 버튼으로 선택, 하나만 활성):
  - `기본 대기` — 자연스러운 숨쉬기 + 미세 움직임
  - `활기찬 대기` — 살짝 통통 튀는 느낌
  - `수줍은 대기` — 손을 모으고 살짝 흔들림
  - `자신감 대기` — 팔짱 낀 상태
  - `댄스 루프` — 리듬에 맞춰 반복 댄스
  - `유영하는` — 물 속에 있는 것처럼 천천히 흔들림

#### [섹션] 감정 / 리액션 동작 (클릭 시 1회 재생)

- 버튼 그리드 (2열):
  - `손 흔들기 👋` | `인사 🙇` | `웃음 😄` | `놀람 😲`
  - `화남 😠` | `슬픔 😢` | `하트 ❤️` | `승리 ✌️`
  - `춤추기 💃` | `박수 👏` | `OK 👌` | `뽀뽀 😘`
  - `윙크 😉` | `잠자기 😴` | `스트레칭` | `점프`

#### [섹션] 표정 (Facial Expression)

- **표정 프리셋** 슬라이더 방식:
  - `기쁨` 0~100 슬라이더
  - `슬픔` 0~100
  - `놀람` 0~100
  - `화남` 0~100
  - `부끄러움` 0~100 (볼이 빨개짐)
- **입 모양** 선택: `다물기` | `살짝 열기` | `크게 웃음` | `말하는 중` | `오`

#### [섹션] 페이스 트래킹 연결

- `웹캠 페이스 트래킹` 토글
  - ON 시 → 웹캠 권한 요청 → 허가 후 실시간 얼굴 인식으로 아바타 표정 자동 반영
  - 눈 깜빡임, 입 열림, 고개 기울기, 시선 방향 추적
- `트래킹 민감도` 슬라이더

### 6-5. 효과 탭

#### [섹션] 파티클 효과

  - `버블` — 투명한 거품 파티클
  - `불꽃` — 불꽃/화염 효과
  - `빛 기둥` — 발 아래서 빛이 솟구침
  - `레인 (비)` — 빗방울 파티클

#### [섹션] 오라 / 글로우

- `오라 색상` 팔레트
- `오라 강도` 슬라이더
- `오라 스타일`: `부드러운` | `불꽃` | `전기` | `마법진` | `홀로그램`

#### [섹션] 특수 시각 효과

- `셀 쉐이딩 강도` 슬라이더 (0: 리얼, 100: 완전 애니풍)

- `깊이감 (DOF)` 토글
- `모션 블러` 토글 + 강도
- `색수차 (Chromatic Aberration)` 토글 + 강도
- `스캔라인` 토글 (사이버펑크 효과)
- `홀로그램 왜곡` 토글

#### [섹션] 배지 / 오버레이 텍스트

- `닉네임 표시` 토글 → 머리 위에 이름 표시 (아바타 닉네임)
- `닉네임 색상` + `폰트 선택`
- `레벨/랭크 배지` 토글 → 이름 옆에 배지 표시
- `말풍선` 토글 → 실시간 채팅 연동 시 최근 채팅이 말풍선으로 표시

## 9. 내보내기 모달

### 진입

헤더 `📤 내보내기` 버튼 클릭

### 내보내기 형식 선택 (탭)

```
[ 이미지 ] [ 영상 ] [ 3D 파일 ] [ 방송 연결 ]
```

#### 이미지 탭

- `PNG (투명 배경)` → 현재 뷰 스냅샷, 배경 제거
- `PNG (배경 포함)` → 현재 배경 포함
- `JPG` → 압축 품질 슬라이더 (60~100)
- 해상도 선택: `720p` | `1080p` | `4K`
- `다운로드` 버튼

#### 영상 탭

- `GIF (3초 루프)` → 현재 재생 중인 애니메이션 기준
- `MP4 (최대 30초)` → 녹화 시작/정지 버튼
- `WebM` → 투명 배경 지원
- 해상도: `720p` | `1080p`
- FPS: `24` | `30` | `60`
- `내보내기` 버튼

#### 3D 파일 탭

- `VRM` → VRChat, VSeeFace 등 호환 (권장)
- `GLB / GLTF` → 범용 3D 포맷
- `FBX` → 언리얼엔진, 유니티 호환
- `OBJ` → 기본 메시만 (텍스처 ZIP 포함)
- `내보내기` 버튼 (진행률 프로그레스바 표시)

#### 방송 연결 탭

- **VTube Studio 연결**: 로컬 API 포트 번호 입력 → `연결 테스트` 버튼 → 성공 시 초록색 "연결됨" 표시
- **OBS 브라우저 소스 URL**: 생성된 URL 복사 버튼 → OBS에서 브라우저 소스로 추가 방법 안내 텍스트 표시
- **MoCoMo 라이브 WHIP**: 현재 `LiveBrowserStudio` 파이프라인에 3D 캔버스 스트림 합성
- **NDI 출력** 토글 (고급 옵션)
- **크로마키 설정**: 배경 색상 선택 (기본 초록) + 키 색상 허용 범위

## 15. 반응형 & 모바일 대응

- **데스크톱 (1280px+)**: 3패널 레이아웃 (좌/중/우)
- **태블릿 (768~1280px)**: 우측 패널이 하단 드로어로 이동, 좌측 패널 아이콘 전용으로 축소
- **모바일 (~768px)**: 전체화면 뷰포트 + 하단 슬라이딩 패널로 전환, 손가락 제스처 조작 (`LiveMobilePortraitHost` 패턴 참고)

## 16. 성능 가이드라인

- 초기 로드: 3초 이내 (스켈레톤 로딩 화면 + 프로그레스바 표시)
- 실시간 슬라이더 편집: 16ms 이하 (60fps 유지)
- 고품질 렌더링 모드 (내보내기 시): 별도 워커에서 처리, UI 블로킹 없음
- 텍스처 레이지 로딩: 갤러리 썸네일 스크롤 시 순차 로드
- 웹 워커로 모프 타겟 계산 분리
