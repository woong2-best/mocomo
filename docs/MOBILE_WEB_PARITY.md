# MoCoMo web ↔ app parity

Goal: **Twitter-class** — website and app are the same product (brand, loops, care). APT stays out of mobile scope.

## Waves

### Wave 1 — Social core
- Global search
- Post detail + comments (+ STAR bookmark)
- Public profiles `/u/[username]`
- Notifications in chrome (header / badge)
- Folk UI kit consistency on every touched screen

### Wave 2 — Discovery & identity
- STAR bookmarks list
- Anime / Culture Wiki browse
- Settings (locale, edit profile)
- Discover hub routes to all surfaces

### Wave 3 — Commerce & live depth
- Used listing create (+ phone-verified seller gate)
- STAR seller “내 판매” list (create/checkout still web-first)
- Live go-live → web studio handoff; in-app watch remains
- Communities channel UX (join + open channel chat)

### Wave 4 — Secondary
- Games hub (catalog → open web play)
- Wallet summary (balances + ledger; payout setup on web)
