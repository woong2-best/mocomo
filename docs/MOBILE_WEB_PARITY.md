# MoCoMo web ↔ app parity

Goal: **Twitter-class** — website and app are the same product (brand, loops, care). APT stays out of mobile scope.

## Waves

### Wave 1 — Social core (in progress)
- Global search
- Post detail + comments (+ STAR bookmark)
- Public profiles `/u/[username]`
- Notifications in chrome (header / badge)
- Folk UI kit consistency on every touched screen

### Wave 2 — Discovery & identity
- STAR bookmarks list
- Anime / Culture Wiki browse
- Settings (locale, edit profile, privacy)
- Fix Discover naming vs web matching `/discover`

### Wave 3 — Commerce & live depth
- Market checkout / sell / orders
- Used listing create / my listings
- Live go-live / clips
- Communities full channel UX

### Wave 4 — Secondary
- Games, voice, cosplay, wallet/premium (as product priority allows)

## IA note

Current app tabs: Home · Market · Used · Messages (plus glass bar).  
Web chrome differs; keep mobile IA until Wave 2, but every demoted surface must remain reachable with full folk polish.
